# 📌 01. Project Overview

**Bhadrak Autonomous College Website** is a modern, responsive and multi-page academic website designed as a real-world front-end development project.

The project represents a college website focused on **Data Science and Mathematics & Computing**, providing a structured digital interface for students, visitors and administrators.

The website demonstrates:

* 🎨 Modern UI/UX design
* 📱 Responsive web development
* 🧭 Multi-page navigation
* 📝 Online application interface
* 👨‍🎓 Student information
* 🖼️ Image gallery
* 🔐 Admin panel interface
* 🚀 GitHub Pages deployment

> **Project Goal:** Build a professional institutional website while demonstrating practical HTML, CSS and JavaScript development skills.
